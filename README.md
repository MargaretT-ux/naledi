# Naledi Stories 🌍 — African Folktales for Children

A beautiful, interactive web app that brings African folktales to life for children. Features read-aloud functionality, paragraph highlighting, and stories from across the African continent — built to work offline and on any device.

Built by [Thato Lepelesana](https://github.com/MargaretT-ux) — EdTech developer from Lesotho 🇱🇸, building learning tools for African children.

---

## 🎯 Problem This Solves

Many African children grow up without access to their own stories in digital format. Most educational apps use Western content that children cannot relate to. Naledi Stories changes that — bringing African folktales to children in a joyful, accessible, and culturally relevant way.

---

## 📱 Features

- 🌍 **4 African folktales** from Lesotho, Ghana, West Africa and East Africa
- 🔊 **Read aloud** — text-to-speech reads each story paragraph by paragraph
- ✨ **Paragraph highlighting** — follows along as the story is read
- 📊 **Reading progress bar** — shows how far through the story you are
- 🏷️ **Age tags** — each story labelled with the right age group
- 📶 **Offline first** — works without internet connection
- 📱 **Mobile friendly** — designed for phones first
- 🌟 **Moral of the story** — every tale ends with a life lesson

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | App structure and content |
| CSS3 | Styling, animations, responsive layout |
| Vanilla JavaScript | Story logic, read-aloud, navigation |
| Web Speech API | Text-to-speech read aloud feature |

No frameworks. No dependencies. No internet required.

---

## 🚀 Getting Started

No installation needed — just open the file in a browser.

```bash
# Clone the repository
git clone https://github.com/MargaretT-ux/naledi-stories.git

# Navigate into the project
cd naledi-stories

# Open in your browser
open index.html
```

Or simply download `index.html` and open it on your phone or computer.

## 🌍 Why This Matters

African children deserve to see themselves in the stories they read. Naledi — meaning "star" in Sesotho — is a reminder that African children are bright, capable, and full of potential. This app is part of a broader EdTech mission to build tools designed specifically for African learners.

> *"Every child deserves to grow up knowing the stories of their own people."*
